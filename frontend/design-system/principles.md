# HackVerse Design Principles

1. Developer-first experience.
2. Minimal over decorative.
3. Function before beauty.
4. Consistent spacing.
5. Border over heavy shadows.
6. White space is intentional.
7. One primary action per screen.
8. Blue/Purple only for branding and primary actions.
9. Every screen should feel calm and trustworthy.
10. Inspired by GitHub, not copied from GitHub.
